## 4. Deep Architectural Findings & Audits

### 🔒 Security Audit
- **Insecure Randomness Eliminated**: Password generator migrated from `Math.random()` to `window.crypto.getRandomValues(new Uint32Array(length))` guaranteeing non-predictable, cryptographically secure passwords for exam portals.
- **Client-Side Sandbox**: All document manipulation executed in browser memory (`pdf-lib`, `pdfjs-dist`). No sensitive user data uploaded to any remote server.
- **XSS & DOM Injection**: No `dangerouslySetInnerHTML` on unescaped inputs. Sanitizer engine strips executable javascript action dictionaries (`/JS`, `/JavaScript`, `/Launch`) from uploaded PDFs.

### 🌐 Privacy & Network Audit
- **Zero External Document Leaks**: Verified that all `fetch()` calls in `src/` operate solely on local `blob:` and `data:` URIs.
- **QR Code Privacy Leak Eliminated**: Formerly transmitted user data and URLs to `https://api.qrserver.com/`. Replaced completely with client-side `qrcode` canvas rendering. 100% offline, zero network requests.
- **PDF.js Worker**: Uses local bundled worker `dist/assets/pdf.worker.min-*.mjs` first, avoiding third-party CDN tracking.

### ⚡ Performance & Memory Audit
- **Presentation Laser Stuttering Fixed**: `mousePos` was in the RAF render loop's `useEffect` dependency array, which destroyed and recreated animation frames on every pointer movement. Replaced with `mousePosRef`, restoring 60 FPS fluidity.
- **Engine Memory Leak Patched**: During document reload (e.g. after rotate, duplicate, or delete), `engine.closeDocument(oldDocId)` is now invoked before registering the new state, preventing memory accumulation.
- **Zip Generation Timestamps**: Fixed hardcoded 0 MS-DOS date/time headers, eliminating extraction warnings in modern unzippers.

### 📱 Responsive & Accessibility Audit
- **Touch Support**: Menu close handlers now listen to both `mousedown` and `touchstart` for reliable mobile dismissal.
- **Mobile Floating Bar**: Renders cleanly on viewports from 320px to 1920px.
- **Non-HTTPS Clipboard Support**: Added `document.execCommand('copy')` fallback for development and non-secure origins where `navigator.clipboard` is unavailable.
- **Tailwind Palette Fixes**: Replaced invalid decimal class `py-0.2` with `py-px`, and non-existent `bg-slate-850` with standard `bg-slate-800/80`.
