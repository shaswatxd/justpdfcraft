# Contributing to SwiftPDF

We welcome contributions to SwiftPDF!

## Development Workflow

1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Verify changes pass all tests and strict type checking:
   ```bash
   npx tsc --noEmit
   npm run test
   ```
5. Submit a pull request with clear descriptions of your changes and test coverage.
